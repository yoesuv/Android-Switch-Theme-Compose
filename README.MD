# Android Switch Light/Dark Theme Compose

Simple Android app to switch Light/Dark theme using Jetpack Compose and Material 3. Theme preference is saved with SharedPreferences.

#### Features

- Light/Dark theme toggle
- Persisted with SharedPreferences
- Material 3 + Compose
